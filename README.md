# 🌴 Calculadora & Presupuesto: Country Club El Bosque (Chosica)

Aplicación web interactiva para calcular y dividir los gastos de un fin de semana en bungaló en el **Country Club El Bosque (Sede Chosica)**, con división justa de alcohol, auto-guardado local y control de tarifa de pernocte.

## ✨ Características Principales

* **🏨 Switch Maestro de Pernocte:**
  * Botón para **prender o apagar** el cobro de pernocte (por defecto S/ 70.00 por invitado).
  * Monto modificable en vivo según lo que confirme la administración de El Bosque (+51 989 160 392).
  * Asignación configurable: solo invitados (amigos), todos, división grupal o selección manual.

* **🍻 Reparto Inteligente de Alcohol:**
  * Fondo de alcohol (cervezas, licores, mixers) repartido **únicamente** entre los que beben.
  * Los que no beben pagan **S/ 0** de alcohol.

* **👥 100% Modificable en Vivo:**
  * Edita los nombres de tus amigos.
  * Añade o elimina integrantes con 1 clic.
  * Ajustes individuales (ej. cuota extra voluntaria, aportes por movilidad/gasolina).
  * Control de pagos (marca con un clic quién ya transfirió por Yape o Plin).

* **🛒 Gestor de Gastos Completo:**
  * Desglose editable de conceptos: bungaló, carnes y parrilla, snacks y hielo, licores y extras.
  * Agrega nuevos gastos en cualquier momento.

* **📲 Botón de Copiado para WhatsApp:**
  * Genera automáticamente un mensaje listo con formato, emojis, cuotas individuales y número de Yape/Plin para pegar en el grupo.

* **💾 Auto-guardado Local:**
  * Todo se almacena en el `localStorage` del navegador para que no pierdas cambios al recargar.
  * Incluye botón para restablecer a los valores por defecto.

## 🚀 Cómo publicarlo gratis en GitHub Pages

Para que tus amigos puedan abrir la calculadora desde su celular con un link:

1. Sube este repositorio a tu cuenta de GitHub:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/presupuesto-el-bosque.git
   git branch -M main
   git push -u origin main
   ```
2. En GitHub, ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú izquierdo, haz clic en **Pages**.
4. En **Build and deployment > Source**, selecciona:
   * Branch: `main`
   * Folder: `/ (root)`
5. Haz clic en **Save**. ¡En 1 minuto tendrás tu enlace activo en `https://TU-USUARIO.github.io/presupuesto-el-bosque/`!
